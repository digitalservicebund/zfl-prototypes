# Prototyp: Vorhaben starten (KI-unterstützt)

Klickbarer Entwurf des Zentrums für Legistik für die frühe Phase der Rechtsetzung. Beispielvorhaben: fiktive Änderung des Wohngeldgesetzes.

Seiten: `index.html` (Start) → `eingabe.html` (Eingabe) → `ergebnis.html` (Empfehlungen).

Klickbar sind nur die blauen Buttons und der Name „Zentrum für Legistik“ oben links (zurück zur Startseite). Alle anderen Links und Buttons sind bewusst ohne Funktion.

## Veröffentlichen mit GitHub Pages

1. Alle Dateien in ein Repository hochladen (`index.html` im Hauptverzeichnis).
2. Unter *Settings › Pages* als Quelle den Branch `main` und den Ordner `/ (root)` wählen.
