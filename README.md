# zfl-prototypes

Space for ZfL prototypes that get deployed via GitHub Pages.

## Deploying a prototype

1. Add your HTML file(s) to the repo, ideally in their own folder, e.g. `my-prototype/index.html`
2. Commit and push to `main`
3. After a minute or two, find it at
   `https://digitalservicebund.github.io/zfl-prototypes/<path-to-file>`
   e.g. https://digitalservicebund.github.io/zfl-prototypes/my-prototype/

An `index.html` is served at its folder's URL, so you can leave it out of the link. Any other file needs its full name, e.g. `.../my-prototype/variant-b.html`.

> ⚠️ Everything pushed here is publicly accessible. Don't include real user data or secrets.
